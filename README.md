# Nova HR — Remote HR Management System

Full-stack HR platform for managing a distributed workforce — recruitment, onboarding, attendance, leave, payslips, 
performance reviews, and admin analytics, with role-based access (Employee/Manager/HR/Admin).

**Stack:** Java, Spring Boot 4, MySQL, React (Vite) + Tailwind, RabbitMQ, JWT auth

**Demo video:** https://youtu.be/UhOLkwa4hL0

## Local setup
Copy `.env.example` to `.env` in `backend/`, fill in real values, then `source .env` before running any `make` target.
